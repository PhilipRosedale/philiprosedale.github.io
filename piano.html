Piano sequence learning

One leaky integrate-and-fire neuron per key, all-to-all connected, all weights starting at zero. STDP strengthens a synapse whose spike arrives just before the target fires — so learning only happens when the conduction delay is close to the note interval. Hover an arc to read its weight.
